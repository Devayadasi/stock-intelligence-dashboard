# 📈 Stock Intelligence Dashboard

A full-stack stock analytics dashboard built using **FastAPI**, **JavaScript**, **Chart.js**, and **yfinance** for real-time stock market analysis and visualization.

---

# 🚀 Features

## 📊 Real-Time Stock Data
- Fetches live stock market data using `yfinance`
- Supports multiple companies:
  - TCS
  - INFY
  - RELIANCE
  - HDFCBANK

---

## 📈 Interactive Charts
- Dynamic stock price visualization using Chart.js
- Real-time chart updates
- Smooth and responsive UI

---

## 📉 Analytics & Metrics
- Daily Return Calculation
- 7-Day Moving Average
- Volatility Analysis
- 52-Week High & Low
- Volume Analysis

---

## 🔄 Compare Stocks
- Compare two stocks using API endpoints
- Analyze latest close and average prices

---

## 🎨 Modern Dashboard UI
- Responsive design
- Sidebar navigation
- Search functionality
- Notification panel
- Editable profile
- Theme toggle
- Loading animations

---

# 🛠️ Tech Stack
